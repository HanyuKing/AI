## 💡 技术亮点

### 1. 模块化设计

```
规格数据 (id_photo_specs.py) ← 独立维护，易扩展
    ↓ 导入
核心处理 (id_photo_utils.py) ← 算法实现
    ↓ 导入
服务层 (id_photo_service.py) ← Server集成
    ↓ 调用
应用层 (API/CLI) ← 用户接口
```

### 2. 向后兼容

```python
# 旧代码仍然有效
processor.generate_id_photo(
    size_name="1inch",  # 旧参数
    bg_color=(255, 255, 255)
)

# 新代码更语义化
processor.generate_id_photo(
    spec_id="driving_license",  # 新参数
    bg_color_name="white"
)
```

### 3. 延迟加载

```python
# Server 启动时不加载重量级库
from practices.id_photo_specs import ID_PHOTO_SPECS  # ✅ 轻量

# 实际使用时才加载
def generate_photo():
    from practices.id_photo_utils import IdPhotoProcessor  # ⏳ 延迟
```

### 4. 智能导入


## ⚠️ 已知限制

### Python 3.13 兼容性

**现象**: 生成证件照时可能报 `pymatting` 错误

**影响**: 
- ✅ Server 启动：正常
- ✅ 规格查询：正常
- ⚠️ 生成照片：需要设置环境变量

**解决方案**:
1. 推荐：使用 Python 3.11 或 3.12
2. 临时：`export NUMBA_CACHE_DIR=/tmp`
3. 详细：查看 `已知问题和解决方案.md`
