# 已知问题和解决方案

## ⚠️ Python 3.13 兼容性问题

### 问题描述

在 Python 3.13 环境下，导入 `id_photo_utils` 时可能会遇到以下错误：

```
RuntimeError: cannot cache function '_make_tree': no locator available 
for file '/opt/anaconda3/lib/python3.13/site-packages/pymatting/util/kdtree.py'
```

### 原因分析

这是 `pymatting` 库（`rembg` 的依赖）与 Python 3.13 的 `numba` 缓存机制不兼容导致的。这是一个已知的上游问题，不是本项目的代码问题。

### 解决方案

有以下几种解决方案：

#### 方案 1: 禁用 Numba 缓存（推荐）

在导入前设置环境变量：

```python
import os
os.environ['NUMBA_CACHE_DIR'] = '/tmp'
os.environ['NUMBA_DISABLE_JIT'] = '0'

from practices.id_photo_utils import IdPhotoProcessor
```

或者在启动脚本前设置：

```bash
export NUMBA_CACHE_DIR=/tmp
python your_script.py
```

#### 方案 2: 使用 Python 3.11 或 3.12

降级到 Python 3.11 或 3.12 版本：

```bash
conda create -n idphoto python=3.11
conda activate idphoto
pip install -r requirements.txt
```

#### 方案 3: 延迟导入（在 Web 服务中推荐）

只在实际需要时才导入：

```python
# 在 API 路由中延迟导入
def generate_photo():
    import os
    os.environ['NUMBA_CACHE_DIR'] = '/tmp'
    
    from practices.id_photo_utils import IdPhotoProcessor
    # ... 处理逻辑
```

#### 方案 4: 更新依赖（等待上游修复）

关注以下项目的更新：
- `pymatting`
- `numba`
- `rembg`

### 验证是否受影响

运行以下命令检测：

```bash
python -c "import sys; print(f'Python版本: {sys.version}'); from practices.id_photo_specs import ID_PHOTO_SPECS; print('✅ 规格数据导入正常')"
```

如果只有规格查询功能，不会受影响。只有在实际生成证件照时才会触发这个问题。

## 🚀 推荐的使用方式

### Web 服务集成

```python
# server/services/id_photo_service.py
import os

class IdPhotoService:
    @staticmethod
    def generate_id_photo(input_path, output_path, spec_id="1inch", bg_color="#FFFFFF"):
        # 设置环境变量（仅需要设置一次）
        os.environ.setdefault('NUMBA_CACHE_DIR', '/tmp')
        
        # 延迟导入
        from practices.id_photo_utils import IdPhotoProcessor
        
        processor = IdPhotoProcessor(input_path)
        result = processor.generate_id_photo(
            spec_id=spec_id,
            bg_color_name="white" if bg_color == "#FFFFFF" else None
        )
        result.save(output_path, quality=95, dpi=(300, 300))
```

### 命令行工具

```bash
# 在脚本开头添加
export NUMBA_CACHE_DIR=/tmp

python id_photo_maker.py
```

### Docker 部署

```dockerfile
ENV NUMBA_CACHE_DIR=/tmp
ENV NUMBA_DISABLE_JIT=0
```
