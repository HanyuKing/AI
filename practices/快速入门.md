### 方式 2️⃣: 快捷命令行（推荐熟手）

```bash
# 制作一寸照片（透明背景）
python id_photo_quick.py images/photo.jpg 1inch transparent
```

**查看可用选项**:
```bash
# 查看所有规格ID

# 查看所有背景颜色
python id_photo_quick.py --list-colors
```

### 方式 3️⃣: 编程集成（推荐开发者）

**特点**: 灵活定制，适合集成到其他系统

```python
from id_photo_utils import IdPhotoProcessor

# 创建处理器
processor = IdPhotoProcessor("images/photo.jpg")

# 生成驾驶证照片
result = processor.generate_id_photo(
    spec_id="driving_license",
    bg_color_name="white",
    use_beautify=True
)

# 保存
result.save("output/driving_license.jpg", quality=95, dpi=(300, 300))
```

**批量处理示例**:
```python
# 运行示例代码
python example_usage.py

# 选项 6: 批量生成多种规格

```

## ❓ 常见问题

### Q: 首次运行很慢？
**A**: 首次运行会自动下载 BiRefNet 模型（约1GB），下载完成后会缓存到本地，后续使用会很快。

### Q: 如何知道某个证件需要什么规格？
**A**: 
1. 使用搜索功能：`python id_photo_maker.py`，选择"搜索规格"
2. 查看完整列表：`python show_all_specs.py`
3. 查看速查表：见上文"常见证件照规格速查"

### Q: 背景颜色如何选择？
**A**: 
- **白色** - 最通用，身份证、护照、驾驶证等
- **蓝色** - 考试报名、学生证、毕业照
- **红色** - 工作证、结婚证
- **透明** - 需要自定义背景时使用

### Q: 照片质量够用吗？
**A**: 输出为 300 DPI，符合打印和电子版提交标准。

### Q: 支持批量处理吗？
**A**: 支持！使用编程方式或编写简单脚本循环调用即可。
