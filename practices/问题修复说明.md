# 问题修复说明

## 🐛 修复的问题

### 问题：ModuleNotFoundError

**错误信息**:
```
ModuleNotFoundError: No module named 'id_photo_specs'
```

**发生场景**:
从 `server/services/id_photo_service.py` 导入时，找不到 `id_photo_specs` 模块。

**根本原因**:
在优化过程中，将证件照规格数据从 `id_photo_utils.py` 分离到 `id_photo_specs.py`，但导入语句使用了不兼容的相对导入方式。

---

## ✅ 解决方案

### 1. 修复模块导入

**修改前**（会失败）:
```python
# id_photo_utils.py
from id_photo_specs import ID_PHOTO_SPECS  # 仅在当前目录运行时有效
```

**修改后**（兼容所有情况）:
```python
# id_photo_utils.py
try:
    from .id_photo_specs import ID_PHOTO_SPECS  # 作为包导入时
except ImportError:
    from id_photo_specs import ID_PHOTO_SPECS  # 直接运行时
```

**适用文件**:
- `practices/id_photo_utils.py`
- `practices/id_photo_maker.py`
- `practices/id_photo_quick.py`
- `practices/example_usage.py`
- `practices/show_all_specs.py`

### 2. 向后兼容

为了不破坏现有代码，添加了向后兼容层：

```python
# 在 id_photo_utils.py 中保留旧的 ID_PHOTO_SIZES
ID_PHOTO_SIZES = {
    "1inch": (25, 35),
    "small_1inch": (22, 32),
    # ... 其他旧规格
}

# 支持旧的 size_name 参数
def generate_id_photo(
    self,
    spec_id: str = None,
    size_name: str = None,  # 向后兼容
    # ...
):
    if size_name and not spec_id:
        spec_id = size_name  # 自动转换
```

### 3. 延迟导入（解决启动问题）

**问题**: Server 启动时立即加载 `rembg`，在 Python 3.13 下会报错。

**解决**: 延迟导入 `IdPhotoProcessor`

```python
# server/services/id_photo_service.py

# ❌ 旧方式：启动时立即导入
# from practices.id_photo_utils import IdPhotoProcessor

# ✅ 新方式：延迟导入
def _lazy_import_processor():
    from practices.id_photo_utils import IdPhotoProcessor
    return IdPhotoProcessor

# 仅在实际使用时导入
def generate_id_photo(...):
    IdPhotoProcessor = _lazy_import_processor()
    processor = IdPhotoProcessor(...)
```

**好处**:
- ✅ Server 可以正常启动
- ✅ 规格查询API正常工作
- ✅ 仅在实际生成证件照时才加载重量级库

## 📋 新增 API

### IdPhotoService 新方法

```python
# 获取所有规格分类
IdPhotoService.get_all_specs()
# 返回: {category_id: {category_name, icon, specs: {...}}}

# 获取指定规格信息
IdPhotoService.get_spec_info("driving_license")
# 返回: {name, size_mm, size_px, common_bg, description, usage}

# 搜索规格
IdPhotoService.search_specs("驾照")
# 返回: [匹配的规格列表]

IdPhotoService.get_background_colors()
# 返回: {color_name: {name, hex, rgb, description}}

# 生成证件照（支持新参数）
IdPhotoService.generate_id_photo(
    input_path="input.jpg",
    output_path="output.jpg",
    spec_id="driving_license",  # 新参数：更语义化
    bg_color="#FFFFFF",
    use_beautify=True
)
```

## ⚠️ 已知限制

### Python 3.13 兼容性

在 Python 3.13 下，实际生成证件照时可能遇到 `pymatting` 兼容性问题：

```
RuntimeError: cannot cache function '_make_tree': no locator available for file ...
```

**解决方案**（选其一）:

1. **使用 Python 3.11 或 3.12**（推荐）
   ```bash
   conda create -n idphoto python=3.11
   ```

2. **设置环境变量**
   ```bash
   export NUMBA_CACHE_DIR=/tmp
   python your_script.py
   ```

3. **代码中设置**
   ```python
   import os
   os.environ['NUMBA_CACHE_DIR'] = '/tmp'
   from practices.id_photo_utils import IdPhotoProcessor
   ```

详细说明见 `已知问题和解决方案.md`。
