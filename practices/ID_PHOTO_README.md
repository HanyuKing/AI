## 快速开始

### 1. 安装依赖

```bash
pip install opencv-python numpy pillow rembg
```

### 2. 查看所有支持的规格

```bash
# 查看所有详细规格
python show_all_specs.py

# 查看分类摘要
python show_all_specs.py summary

# 查看背景颜色
python show_all_specs.py colors
```

### 3. 制作证件照（交互式）

```bash
python id_photo_maker.py
```

交互式界面会引导您完成以下步骤：
1. 📁 选择输入照片
2. 📋 选择证件类型（按场景分类浏览或搜索）
3. 🎨 选择背景颜色
4. ✨ 选择是否美颜
5. ✅ 确认并生成

### 4. 编程方式调用

```python
from id_photo_utils import IdPhotoProcessor

# 创建处理器
processor = IdPhotoProcessor("input.jpg")

# 方式1: 生成驾驶证照片（白底）
result = processor.generate_id_photo(
    spec_id="driving_license",
    bg_color_name="white",
    use_beautify=True
)
result.save("output/driving_license.jpg", quality=95, dpi=(300, 300))

# 方式2: 生成公务员考试照片（蓝底）
result = processor.generate_id_photo(
    spec_id="civil_servant",
    bg_color_name="blue",
    use_beautify=True
)
result.save("output/civil_servant.jpg", quality=95, dpi=(300, 300))

# 方式3: 生成护照照片（透明背景）
result = processor.generate_id_photo(
    spec_id="passport",
    bg_color=None,  # 透明背景
    use_beautify=True
)
result.save("output/passport.png", dpi=(300, 300))
```

## 技术参数

- **抠图模型**: BiRefNet-portrait（SOTA 人像分割模型）
- **输出 DPI**: 300（印刷级质量）
- **输出格式**: JPG（有底色）/ PNG（透明背景）
- **美颜算法**: 双边滤波 + HSV 亮度调整
- **智能裁剪**: 保留头部区域，自动适配宽高比

## 常见问题

### Q1: 首次运行很慢？
**A**: 首次运行会自动下载约 1GB 的 BiRefNet 模型，请耐心等待。后续使用会自动加载本地模型。

### Q2: 能否批量处理？
**A**: 可以编写简单脚本调用 `IdPhotoProcessor` 类进行批量处理。

### Q3: 如何添加新的证件照规格？
**A**: 编辑 `id_photo_specs.py` 文件，在对应分类下添加新的规格定义即可。

### Q4: 照片质量不满意？
**A**: 可以调整美颜参数 `smooth_strength` 和 `brighten_strength`，或者关闭美颜功能。

### Q5: 背景色不标准？
**A**: 可在 `id_photo_specs.py` 的 `BG_COLOR_PRESETS` 中修改 RGB 值。
