# 证件照裁剪功能 - 使用指南

## 功能特性

### ✨ 核心功能
1. **智能裁剪** - 使用 Cropper.js 提供专业级的裁剪体验
2. **自动抠图** - 基于 BiRefNet-Portrait 模型的 SOTA 人像分割
3. **背景替换** - 支持自定义颜色，包括常用的白/蓝/红底
4. **智能美颜** - 磨皮 + 美白处理
5. **标准尺寸** - 支持 6 种常见证件照规格
6. **高清输出** - 300 DPI，达到商业打印标准

### 📐 支持的尺寸规格
- **一寸**: 25mm × 35mm
- **小一寸**: 22mm × 32mm
- **大一寸**: 33mm × 48mm
- **二寸**: 35mm × 49mm
- **小二寸**: 33mm × 48mm
- **大二寸**: 35mm × 53mm

### 🎨 用户界面特性
- 拖拽上传支持
- 实时预览
- 裁剪工具（旋转、翻转、重置）
- 响应式设计，支持移动端
- 渐变动画和过渡效果
- 清晰的步骤引导

## 使用流程

### 1. 上传照片
- 点击上传区域或拖拽图片
- 支持 JPG、PNG、BMP、WEBP 格式

### 2. 调整裁剪区域
- 拖动裁剪框调整位置
- 拉伸角落调整大小
- 使用工具栏进行旋转、翻转

### 3. 设置参数
- 选择证件照尺寸（自动调整裁剪框比例）
- 选择背景颜色
- 开启/关闭美颜功能

### 4. 生成和下载
- 点击"生成证件照"按钮
- 等待处理完成（首次可能需要下载模型）
- 下载生成的证件照

## 技术架构

### 后端技术栈
- **FastAPI** - Web 框架
- **rembg** - 背景移除（BiRefNet-Portrait 模型）
- **OpenCV** - 图像处理
- **PIL/Pillow** - 图像操作

### 前端技术栈
- **Cropper.js** - 专业裁剪库
- **Tailwind CSS** - 样式框架
- **Vanilla JavaScript** - 交互逻辑

### API 端点
```
POST /api/media/image/id-photo
```

**参数:**
- `file`: 图片文件（multipart/form-data）
- `size`: 尺寸规格（如 "1inch", "2inch"）
- `bg_color`: 背景颜色（十六进制，如 "#FFFFFF"）
- `beautify`: 是否启用美颜（boolean）

**返回:**
- PNG 格式的证件照图片

## 性能优化

### 已实现的优化
1. **前端裁剪** - 在浏览器端裁剪，减少上传数据量
2. **Canvas 优化** - 使用高质量的图像平滑算法
3. **异步处理** - 非阻塞式图片生成
4. **临时文件清理** - 自动清理服务器临时文件

### 进一步优化建议
1. **缓存模型** - BiRefNet 模型约 1GB，首次加载较慢，建议预加载
2. **批量处理** - 支持一次上传多张照片
3. **WebP 输出** - 可选择更小体积的 WebP 格式
4. **进度条** - 显示抠图和处理的详细进度
5. **预览优化** - 使用 WebWorker 处理预览，避免阻塞主线程

## 部署注意事项

### 服务器要求
- **内存**: 建议 4GB+ (BiRefNet 模型需要约 2GB)
- **存储**: 模型文件约 1GB
- **Python**: 3.8+
- **依赖**: 见 `requirements.txt`

### 首次启动
```bash
# 安装依赖
pip install -r requirements.txt

# 首次运行会自动下载模型（约 1GB）
# 请确保网络畅通，下载可能需要几分钟

# 启动服务
python server/app.py
```

### 生产环境配置
```bash
# 使用 Gunicorn + Uvicorn Worker
gunicorn server.app:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000

# 或使用 Supervisor 管理进程
# 配置文件见 deploy/ 目录
```

## 常见问题

### Q: 首次处理很慢？
A: 首次运行需要下载 BiRefNet-Portrait 模型（约 1GB），之后会缓存到本地。

### Q: 处理大图很慢？
A: 建议在前端先压缩到合理尺寸（如 1920px），再上传。

### Q: 抠图效果不理想？
A: BiRefNet 是目前最先进的人像分割模型，如果效果不佳，可能是原图质量问题（光线、背景复杂度）。

### Q: 支持批量处理吗？
A: 当前版本不支持，可以在未来版本中添加。

### Q: 可以商用吗？
A: 代码可商用，但请注意：
- BiRefNet 模型的许可证
- 确保符合当地法律法规
